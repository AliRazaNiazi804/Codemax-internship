# Learning Notes: Introduction to AI & Python

## 1. What is Artificial Intelligence?
AI is the field of building computer systems that perform tasks that normally need human intelligence, such as understanding language, recognising images, making decisions and solving problems.

## 2. AI vs Machine Learning vs Deep Learning
| Term | Meaning | Example |
|------|---------|---------|
| **AI** | The broad goal of making machines "smart" | A chess-playing program |
| **Machine Learning (ML)** | A subset of AI where systems learn patterns from data instead of following hand-written rules | Spam email filter |
| **Deep Learning (DL)** | A subset of ML using multi-layer neural networks, great for images, speech and text | Face recognition, ChatGPT-style models |

Think of nested circles: **AI ⊃ ML ⊃ Deep Learning**.

## 3. Types of Machine Learning
- **Supervised learning**: learns from labelled data (e.g. house prices from past sales).
- **Unsupervised learning**: finds hidden patterns in unlabelled data (e.g. customer grouping).
- **Reinforcement learning**: learns by trial, reward and penalty (e.g. game-playing agents, robots).

## 4. How ML works (simple view)
1. Collect data
2. Clean and prepare it
3. Train a model
4. Test and evaluate it
5. Deploy and improve

## 5. Real-world AI applications
- **Healthcare**: detecting diseases in X-rays and scans
- **Finance**: fraud detection, credit scoring
- **Transport**: self-driving features, route optimisation
- **Retail/Entertainment**: Netflix, YouTube and Amazon recommendations
- **Smartphones**: voice assistants, face unlock, translation
- **Agriculture**: crop disease detection from photos
- **Education**: personalised learning and tutoring tools

## 6. Python basics I practiced
- **Variables**: store data (`name = "Ali"`). Types: int, float, str, bool.
- **Loops**: `for` repeats over a sequence, `while` repeats until a condition is false.
- **Functions**: reusable blocks of code (`def add(a, b): return a + b`).
- **Lists**: ordered, changeable collections (`[1, 2, 3]`) with methods like `append`, `remove`, `sort`.

## 7. Why Python for AI?
Simple syntax, huge community, and powerful libraries: NumPy, pandas, scikit-learn, TensorFlow, PyTorch.

## 8. Setup steps
1. Download Python from python.org (tick "Add Python to PATH" on Windows)
2. Verify with `python --version`
3. Use VS Code or IDLE to write and run programs
